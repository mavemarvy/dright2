# KDP Publishing Toolkit

## Reader & Market Brief
Reader / problem or desired experience / comparable books / review gaps / topic depth / rights risks / positioning.

## Book Blueprint
Reader promise / title ideas / subtitle ideas / chapter outcomes / source map / exercises or illustrations / word-count range.

## Rights Ledger
Asset / creator / source / licence or ownership basis / territory notes / proof stored / approved for use.

## Metadata Sheet
Title / subtitle / author / description / keywords / categories / publishing rights / territories / format / list price / ISBN choice.

## Pre-Publish QA
Manuscript version, spelling, navigation, ebook preview, print trim/margins/bleed, cover dimensions, metadata match, rights checked and current KDP policies reviewed.

## Launch Review
Traffic source / units / royalty reports / reader questions / reviews / ad spend if any / changes needed / next-title hypothesis.
