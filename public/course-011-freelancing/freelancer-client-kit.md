# Freelancer Client Kit

## Service Definition
Target client / problem / deliverable / turnaround / required inputs / revision limit / exclusions / success criteria.

## Job Scorecard
Fit 1–5, client clarity 1–5, budget fit 1–5, proof match 1–5, timeline fit 1–5, risk flags and apply/no-bid decision.

## Proposal Framework
1. Show you understood the specific goal.
2. Give one relevant proof or sample.
3. Explain the first 2–3 steps.
4. Ask one useful question.
5. Offer a simple next step.

## Discovery Call
Goal, current process, audience, deadline, files, decision maker, previous attempts, constraints, quality criteria and budget/timeline.

## Scope & Revision Rule
Define deliverables and what counts as a correction versus new scope. Confirm extra work before doing it.

## Handoff
Delivered files / version / what changed / instructions / limitations / next step / feedback request.
