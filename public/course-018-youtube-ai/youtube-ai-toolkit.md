# YouTube AI Production Toolkit

## Channel Brief
Audience / recurring value / content pillars / original contribution / production budget / upload capacity / sensitive-topic risks.

## Research Brief
Video question / viewer promise / primary sources / supporting sources / facts to verify / uncertainty / expert escalation where needed.

## Script QA
Hook fulfilled, sources checked, no invented quotes, no copied passages, clear transitions, original examples, visuals planned and CTA appropriate.

## Asset Rights Ledger
Asset / source / licence / attribution required / allowed use / file location / notes.

## Packaging Sheet
Ten title options / three thumbnail concepts / promise match / mobile readability / experiment plan.

## Upload QA
Description, chapters, captions, links, disclosures, thumbnail, end screens, copyright checks and monetization-policy review where relevant.

## Monthly Review
Topics, impressions, CTR, retention, returning viewers, production cost, revenue if any, viewer questions and keep/change/stop decisions.
