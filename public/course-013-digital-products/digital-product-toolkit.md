# Digital Product Builder Kit

## Product Brief
Buyer / repeated problem / desired outcome / product format / why this format / included files / exclusions / device requirements / validation evidence.

## Validation
Competitors reviewed / customer language / three demand signals / prototype shown / feedback / pass-fail threshold / decision.

## Build Checklist
Outline → worked examples → instructions → mobile test → formula or file test → spelling → accessibility → export → delivery test.

## Product Page
Outcome-focused title, subtitle, exact contents, previews, compatibility, limitations, support, access or delivery, price, affiliate terms where applicable and FAQ.

## Launch Plan
Pre-launch education / demo / FAQ / proof / genuine opening / reminder / genuine deadline only when one exists.

## Version Log
Version / date / changes / reason / buyer impact / whether existing buyers receive update.
