# Affiliate Sales Toolkit

## Offer Scorecard
Audience fit / product usefulness / price fit / actual commission per sale / reversal risk / program reputation / traffic permissions / payout timing / disclosure requirements.

## Content Brief
Buyer question / journey stage / hook / useful teaching / proof or demo / limitation / affiliate disclosure / CTA / tracked link.

## WhatsApp Follow-up
Ask the buyer's need → clarify fit → answer objections truthfully → share the correct tracked link → follow up reasonably → respect opt-out.

## Disclosure Example
“This is an affiliate link. I may earn a commission if you buy through it, at no extra cost to you.”

## Funnel Review
Views → qualified clicks → sales → conversion rate → commission → reversals/refunds → commission per click.

## Stop Rules
Pause an offer if quality declines, reversal rate becomes unacceptable, rules change, or promotion requires misleading claims.
